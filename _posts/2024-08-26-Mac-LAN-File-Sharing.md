## 背景

在团队协作中，经常需要在同事之间快速共享文件。常见的方式包括：

1. **即时通讯工具** - 微信、钉钉等，但大文件传输慢
2. **邮件** - 附件大小限制，不适合大文件
3. **云盘** - 需要上传下载，步骤繁琐
4. **U盘/移动硬盘** - 需要物理接触，不方便

其实，Mac 系统自带了局域网文件共享功能，可以在同一网络下的 Mac 之间快速共享文件，速度非常快，而且操作简单。

## 适用场景

- 团队内部快速共享大文件
- 项目组共享开发资源
- 设计师共享设计稿
- 临时文件传输

## 操作步骤

### 步骤一：文件共享人配置

#### 1. 打开文件共享功能

1. 点击左上角苹果菜单 → **系统设置**（或系统偏好设置）
2. 选择 **通用** → **共享**
3. 开启 **文件共享** 开关

#### 2. 创建共享目录

在 `/Users/Shared` 目录下创建待分享的目录：

```bash
# 打开终端
cd /Users/Shared

# 创建共享目录
mkdir yoohoo

# 设置目录权限（可选）
chmod 755 yoohoo
```

#### 3. 添加共享目录

1. 在 **文件共享** 设置页面，点击 **选项** 按钮
2. 点击 **+** 号添加共享目录
3. 选择刚创建的 `/Users/Shared/yoohoo` 目录
4. 设置相应的权限：

**权限说明：**

| 权限 | 说明 |
|------|------|
| **读与写** | 可以查看和修改文件 |
| **只读** | 只能查看，不能修改 |
| **写（ dropping ）** | 只能放入文件，不能查看 |
| **自定** | 自定义权限设置 |

**推荐设置：**
- 如果是团队共享，设置为 **读与写**
- 如果是单向共享，设置为 **只读**

### 步骤二：文件读取方访问

#### 1. 打开前往服务器

1. 打开 **访达**（Finder）
2. 点击菜单栏 **前往** → **前往服务器**（或按快捷键 `Command + K`）

#### 2. 输入服务器地址

在弹出的对话框中输入共享地址：

```
smb://<IP地址>/<共享目录名>
```

**示例：**
```
smb://192.168.110.74/yoohoo
```

**参数说明：**
- `192.168.110.74` - 文件共享人的 IP 地址
- `yoohoo` - 共享目录名称

#### 3. 输入用户名密码

系统会提示输入文件共享人的用户名和密码：

1. 输入文件共享人的 Mac 登录用户名
2. 输入对应的密码
3. 点击 **连接**

#### 4. 访问共享文件

连接成功后，会在访达中显示共享目录：

- 可以查看目录中的所有文件
- 根据权限设置，可以读取或修改文件
- 像操作本地文件一样操作共享文件

## 实用技巧

### 技巧一：创建桌面快捷方式

为了方便访问，可以创建桌面快捷方式：

1. 在访达中找到已连接的共享目录
2. 按住 `Option + Command` 键
3. 将目录拖拽到桌面

或者使用终端命令：

```bash
# 创建符号链接
ln -s /Volumes/yoohoo ~/Desktop/共享目录
```

### 技巧二：自动连接共享

如果经常访问同一个共享目录，可以设置为自动连接：

1. 打开 **系统设置** → **通用** → **登录项**
2. 点击 **+** 号
3. 选择已连接的共享目录
4. 点击 **添加**

这样每次登录 Mac 时，会自动连接到共享目录。

### 技巧三：查看 IP 地址

如果不知道文件共享人的 IP 地址，可以通过以下方式查看：

**方法一：系统设置**
1. 打开 **系统设置** → **网络**
2. 查看当前连接的网络信息
3. IP 地址显示在网络信息中

**方法二：终端命令**
```bash
# 查看 IP 地址
ifconfig | grep "inet " | grep -v 127.0.0.1
```

**方法三：菜单栏**
1. 按住 `Option` 键
2. 点击菜单栏的网络图标
3. 查看 IP 地址信息

### 技巧四：优化传输速度

**1. 使用有线网络**
- 有线网络比无线网络更稳定，速度更快
- 建议使用千兆以太网

**2. 关闭不必要的共享**
- 只共享必要的目录
- 避免共享大量小文件

**3. 使用压缩**
- 对于大量小文件，先打包成 zip 再传输
- 可以减少传输时间

## 常见问题

### 问题一：无法连接到共享目录

**可能原因：**
1. 两台电脑不在同一局域网
2. 文件共享功能未开启
3. 防火墙阻止了连接
4. IP 地址输入错误

**解决方案：**
1. 确认两台电脑在同一网络
2. 检查文件共享功能是否开启
3. 临时关闭防火墙测试
4. 确认 IP 地址和共享目录名称正确

### 问题二：连接速度慢

**可能原因：**
1. 网络带宽不足
2. 同时访问的用户过多
3. 共享目录文件过多

**解决方案：**
1. 使用有线网络
2. 减少同时访问的用户数
3. 优化共享目录结构

### 问题三：无法修改文件

**可能原因：**
1. 权限设置不正确
2. 文件被其他用户占用
3. 文件系统不支持

**解决方案：**
1. 检查共享目录的权限设置
2. 确认文件未被其他用户打开
3. 使用支持的文件系统（如 APFS、HFS+）

## 安全建议

### 1. 使用强密码

- 为 Mac 账户设置强密码
- 定期更换密码
- 不要使用简单密码

### 2. 限制访问权限

- 只共享必要的目录
- 设置合适的权限级别
- 定期审查共享列表

### 3. 使用防火墙

- 开启 Mac 防火墙
- 只允许信任的 IP 访问
- 定期更新防火墙规则

### 4. 监控访问日志

```bash
# 查看文件共享日志
log show --predicate 'subsystem == "com.apple.smbd"' --last 1h
```

## 高级配置

### 配置 SMB 协议版本

如果需要指定 SMB 协议版本，可以在终端中配置：

```bash
# 编辑 SMB 配置
sudo nano /etc/nsmb.conf

# 添加配置内容
[default]
protocol_vers_map=3
```

### 配置访问控制列表（ACL）

对于更精细的权限控制，可以使用 ACL：

```bash
# 查看 ACL
ls -le /Users/Shared/yoohoo

# 添加 ACL
chmod +a "user:username allow read,write" /Users/Shared/yoohoo

# 移除 ACL
chmod -a "user:username allow read,write" /Users/Shared/yoohoo
```

## 推荐工具：LocalSend

如果你觉得 Mac 自带的 SMB 文件共享配置步骤繁琐（需要开共享、记 IP、输密码），强烈推荐试试 [LocalSend](https://localsend.org/)。

### 什么是 LocalSend

LocalSend 是一款**开源免费**的跨平台局域网文件传输工具，类似 AirDrop，但支持所有主流操作系统：

- macOS
- Windows
- Linux
- Android
- iOS

### 为什么推荐

| 特性 | Mac 自带 SMB 共享 | LocalSend |
|------|-------------------|-----------|
| 跨平台 | 仅 Mac 之间 | 全平台互通 |
| 配置难度 | 需开共享、记 IP、输密码 | 打开即用，零配置 |
| 设备发现 | 手动输入地址 | 自动发现局域网设备 |
| 传输方式 | 挂载共享目录 | 点对点直接发送文件 |
| 加密 | 依赖 SMB 协议 | 端到端加密 |
| 开源 | 系统自带 | [GitHub 开源](https://github.com/localsend/localsend) |

### 安装方式

```bash
# 方式一：Homebrew 安装（推荐）
brew install localsend

# 方式二：官网下载
# https://localsend.org/
```

### 使用方法

1. 所有设备启动 LocalSend（需在同一局域网）
2. 发送方选择文件，自动发现接收方设备
3. 点击目标设备，一键发送
4. 接收方确认接收，完成传输

**使用场景：**
- Mac 和 Windows 之间互传文件
- 手机和电脑之间快速传图
- 多台设备同时传输，无需逐一配置

> **总结：** 如果是 Mac 之间长期共享目录，用系统自带的 SMB 就够了；如果是临时文件传输、跨平台场景，LocalSend 体验更好，强烈推荐。

## 总结

Mac 局域网文件共享是一个简单实用的功能，可以帮助团队快速共享文件。

**核心要点：**

1. **开启文件共享** - 系统设置 → 通用 → 共享 → 文件共享
2. **创建共享目录** - 在 `/Users/Shared` 下创建目录
3. **访问共享** - 访达 → 前往服务器 → 输入 `smb://IP/目录`
4. **输入凭据** - 输入文件共享人的用户名和密码

**优势：**

- 速度快 - 局域网传输，速度远超互联网
- 操作简单 - 无需额外软件，系统自带
- 安全可靠 - 在同一网络内传输，安全性高

掌握这个技巧，可以大大提高团队协作效率！
